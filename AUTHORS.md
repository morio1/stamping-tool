# Development

Project: [Cert Stamp Pro](https://github.com/morio1/stamping-tool)

Cert Stamp Pro is a locally operated Python application for batch certificate stamping, visible signature placement, per-page preview, and auditable PDF export.

Developer attribution appears in the application and project documentation. It is not added to processed certificates or signature images.
